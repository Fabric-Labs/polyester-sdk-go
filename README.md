# Polyester Go SDK

Go SDK for the Polyester public API.

Generated protobuf, ConnectRPC, and Protovalidate packages live in `gen/`.
The repository root contains SDK entry points and helper APIs.

This SDK is maintained by Fabric Labs and updated as the public API evolves.

Go package imports use `github.com/Fabric-Labs/polyester-sdk-go/gen/...`.

## Install

Package tagging is not enabled yet. Until the first release, consume this module
from GitHub at a specific commit.

## Development

```bash
go test ./...
```
